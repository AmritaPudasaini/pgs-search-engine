# OpenSearch ETL

The ETL OpenSearch service indexes the transformed JSONL output generated by
the Airflow pipeline. The indexer uses each document's `document_id` as the
OpenSearch `_id`, so rerunning the indexer replaces matching documents instead
of creating duplicates.

## Configuration

The configuration is defined in `ETL/docker-compose.yml`:

| Setting | Default |
| --- | --- |
| OpenSearch image | `opensearchproject/opensearch:2.17.1` |
| URL from the indexer | `http://opensearch:9200` |
| Host URL | `http://localhost:9200` |
| Username | `admin` |
| Indexer password | `openpassword` |
| Index name | `pgs_documents` |
| Input inside the indexer | `/data/transformed_documents.jsonl` |

The OpenSearch security plugin is disabled for local development. The indexer
still receives the configured `admin` and `openpassword` credentials, but this
local service does not require authentication. Do not expose it to an
untrusted network. `OPENSEARCH_INITIAL_ADMIN_PASSWORD` is retained in Compose
for image compatibility, but it has no effect while security is disabled.

Override the URL or index when needed:

```powershell
$env:OPENSEARCH_URL = "http://opensearch:9200"
$env:OPENSEARCH_INDEX = "pgs_documents"
```

## Start the service

From the `ETL/` directory:

```powershell
docker compose up -d opensearch
```

Wait for the health check, then verify the service:

```powershell
Invoke-RestMethod http://localhost:9200/_cluster/health
```

## Run the complete ETL flow

Start the full ETL stack:

```powershell
cd D:\pgs-search-engine\ETL
docker compose up --build -d
```

Open Airflow at http://localhost:8080 and sign in with `airflow` / `airflow`.
Publish the sample Kafka signal:

```powershell
docker compose run --rm ingestion-signal-publisher
```

Trigger the `etl_ingestion_pipeline` DAG in Airflow. After it succeeds, run:

```powershell
docker compose run --rm opensearch-indexer
```

The DAG writes the transformed records to
`airflow/data/processed/transformed_documents.jsonl`. The indexer mounts this
directory read-only, creates the `pgs_documents` mapping if necessary, and
bulk-indexes every non-empty JSONL record. It reports the line number for
invalid JSON or records without a non-empty `document_id`.

## Inspect the index

```powershell
Invoke-RestMethod http://localhost:9200/pgs_documents/_mapping
Invoke-RestMethod 'http://localhost:9200/pgs_documents/_search?pretty=true'
```

The mapping defines analyzed full-text fields for `title` and
`searchable_text`, keyword fields for exact-match metadata, numeric counts,
duplicate information, and geo-location fields.

## Troubleshooting and shutdown

View service logs:

```powershell
docker compose logs -f opensearch
docker compose logs -f opensearch-indexer
```

Stop the ETL services while keeping the OpenSearch data volume:

```powershell
docker compose down
```

To also delete the local OpenSearch data volume, which removes indexed data:

```powershell
docker compose down -v
```
